# 5L-TEP: material suplementar da dissertação

Material de apoio da dissertação *5L-TEP: um modelo de cinco camadas de engenharia de confiança para dados abertos governamentais*, do Mestrado Profissional em Engenharia de Software da CESAR School. Autor: Luciano Santos Pinheiro. Orientador: Prof. Dr. Anderson Tenório Sérgio.

As cinco camadas do modelo ficam em repositórios próprios, com resultados gerados no GitHub Actions. Este repositório guarda o material que a dissertação cita e que não pertence a nenhuma camada.

| Pasta | Conteúdo | Onde é citado |
|---|---|---|
| [`rsl/`](rsl/) | Revisão sistemática: consultas, registros da OpenAlex, decisão de triagem de cada registro e scripts | Seção 3.1 e Apêndice D |
| [`analise1996/`](analise1996/) | Verificação exploratória do salto de janeiro de 1996 nos autos de infração do IBAMA | Seção 5.7, Tabela 27 |

Nenhuma das duas pastas é resultado das camadas. São análises feitas pelo pesquisador e estão aqui para que possam ser conferidas.

## English summary

Supplementary material for the master's dissertation on the 5L-TEP trust-engineering model for open government data. `rsl/` holds the reproducible systematic literature review based on OpenAlex. `analise1996/` holds an exploratory check of the January 1996 spike in IBAMA infraction records. The dissertation is written in Portuguese, and so is the documentation.
